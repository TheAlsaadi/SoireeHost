Security

What protects your PC and your sites right now. SoiréeHost guards the way in to a site and limits the damage if one is broken into. It cannot fix flaws inside an app you host.

Reaching this PC

  • On

    No open ports

    Nothing on this PC accepts connections from the internet. Visitors arrive through the tunnel, which your PC opens outwards.

  • On

    Windows Firewall rules

    Block incoming connections to SoiréeHost and to the tunnel program.

  • On

    Tunnel program check

    cloudflared.exe is compared with the copy built into SoiréeHost before every start. It matched at 09:14.

  • On

    Unknown addresses refused

    A request for any address that is not one of your sites gets “not found”.

Requests to your sites

  • On, 1 exception

    Web application firewall

    Blocks common attacks, such as SQL injection and cross-site scripting, using the OWASP Core Rule Set.

    • Notes API is set to Detect only. Attacks are logged but not blocked.
  • On

    Rate limits

    Each visitor can make up to 300 requests a minute to a site, unless you change it for that site.

  • On

    Hidden files refused

    Files such as .env, .git, private keys and backups are never served, even if they are in a site’s folder.

  • On

    Security headers

    Tell browsers not to frame your sites, guess file types or leak the page address to other sites.

  • On

    Local apps only

    Proxy sites can reach apps on this PC only, not other devices on your network.

Settings and secrets

  • Not set up

    Tunnel token

    Gives your sites a permanent address on your own domain. Without it, sites go online through temporary quick share links.

  • On

    Settings protected

    Only the SoiréeHost service and administrators can change the settings files. Their permissions are checked at every start.

  • On

    Web server kept apart

    The web server and the tunnel run under their own Windows accounts, cannot start other programs and cannot read your secrets.

  • Intact

    Change history

    Every change to settings is recorded in a log that cannot be rewritten. Checked at 14:02: no entries missing or altered.
