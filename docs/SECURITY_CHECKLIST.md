# Security checklist

Every S-ID from docs/PLAN.md with the test that proves it and its latest result. A requirement with no passing test or recorded manual check is **not met**. Test types are defined in docs/TEST_PLAN.md.

Status values: **Not started**, **Partial** (some of it tested), **Pass**, **Fail**, **Manual** (recorded manual check, with date).

Last updated: 12 Nov 2026, end of Phase 2. The CI `isolation` job installed SoiréeHost on a throwaway Windows runner and passed all eight checks in `internal/e2e`, a reinstall over the running install, and a clean uninstall (pull request 2, run 43281534909). `FuzzDecodeRequest` and `FuzzDecodeWorkerMsg` each ran 10 minutes locally without a crash. End of Phase 1: Phase 1 was merged through pull request 1, with CI green on the pull request (run 43232776044) and on `main` after the merge (run 43236752556). Phase 0's first green CI run: 43191377974. The symbolic-link cases in `TestPathTraversalSuite` only log, rather than fail, if the runner cannot create links; the job log needs a GitHub sign-in and was not read, so whether they ran is not confirmed. Test names refer to `internal/config`, `internal/sitecheck` and `internal/worker` unless a path is given. Fuzz targets `FuzzDecode`, `FuzzHostname`, `FuzzTarget`, `FuzzRootSyntax`, `FuzzCheckStatic` and `FuzzCheckProxy` each ran 10 minutes locally on 12 Nov 2026 without a crash.
