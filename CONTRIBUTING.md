# Contributing

SoiréeHost is published so anyone can read, build and reuse the code under the Apache-2.0 licence. It does not accept outside code.

- **Pull requests from outside the project are closed without merging.** Pull requests stay enabled only so the project's own update automation can propose dependency updates.
- **Bug reports are welcome.** Open an issue with the SoiréeHost version, your Windows version and the steps to reproduce.
- **Security problems** must not go in a public issue. Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability").

You are free to fork the project under the terms of the licence.
